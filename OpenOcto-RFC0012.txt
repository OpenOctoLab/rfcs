                   Standard Library Extensions: the @octo Publisher

Abstract

   This document reserves one publisher name in the package namespace
   of [RFC0013]: @octo, whose packages extend the standard library of
   OctoScript [RFC0003].  An @octo package is reached by the same
   import path as any other package, and what it publishes joins the
   core library of Section 10.2 of [RFC0003] without replacing any of
   it.

   This document is a skeleton.  Its scope and its section names are
   fixed so that [RFC0003] and [RFC0013] can refer to it; the
   substance of each section is to be written.

1.  Introduction

   To be written.  This section will say what an extension of the
   standard library is for, why it travels as a package rather than as
   part of the language document, and how it differs from the
   extension part of the library that [RFC0003], Section 10.2 leaves
   open.

2.  Conventions

   To be written.  This section will fix the meaning of the key words
   and will say how a name of this document is written inside an
   import path of [RFC0003].

3.  The Reserved Name @octo

   To be written.  This section will reserve @octo as a publisher name
   of [RFC0013], will say who MAY publish under it, and will say what
   an implementation MUST do with a package that claims it.

4.  What an Extension May Add

   To be written.  This section will bound what an @octo package
   publishes -- functions, structs and members -- and what it MUST
   NOT: no new syntax, no new operator, and no change to a name the
   core library already holds.

5.  Naming and Versioning

   To be written.  This section will fix the form of an @octo package
   name and the version rule its import path carries.

6.  Conformance

   To be written.  This section will state what a host MUST do to
   claim support for @octo packages.
